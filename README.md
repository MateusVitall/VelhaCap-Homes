# Meu TCC - Imóveis

Projeto de TCC para plataforma de gestão de imóveis.

## Tecnologias

- **Backend**: Node.js + TypeScript + Express + Prisma
- **Frontend**: React + TypeScript + Vite + Tailwind CSS

## Instalação

### Backend
```bash
cd backend
npm install
```

### Frontend
```bash
cd frontend
npm install
```

## Variáveis de Ambiente

Crie um arquivo `.env` na raiz do backend com as configurações necessárias.

## Desenvolvimento

```bash
# Backend
cd backend
npm run dev

# Frontend
cd frontend
npm run dev
```

## Build

```bash
# Backend
cd backend
npm run build

# Frontend
cd frontend
npm run build
```
